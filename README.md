# Publisher website (GitHub Pages)

1. Open `config.js` and put in your studio name, support email, Asset Store link and products.
2. Go to https://github.com/new
   - Repository name: `YOURUSERNAME.github.io` (your exact GitHub username)
   - Public, then **Create repository**
3. Click **uploading an existing file**, drag in all files from this folder
   (`index.html`, `privacy.html`, `style.css`, `config.js`, `site.js`) and click **Commit changes**.
4. Go to **Settings → Pages**. Under "Build and deployment" choose
   **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
5. Wait 1–2 minutes. Your site is live at `https://YOURUSERNAME.github.io`.
6. Paste that URL into the Website field of your Unity publisher profile.
   The privacy policy is at `https://YOURUSERNAME.github.io/privacy.html` if Unity asks for one.
